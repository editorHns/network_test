# Network Test — клиент-серверное взаимодействие

Учебное решение задания «Network Test».

## Что реализовано

- сервер на C++ через TCP sockets;
- простой HTTP-протокол поверх TCP;
- endpoint `GET /api/calc?a=10&b=20`;
- endpoint `GET /health`;
- отдельный клиент на Python;
- нагрузочное тестирование через k6;
- Makefile для сборки;
- шаблон отчёта.

## 1. Сборка

Linux / WSL:

```bash
make
```

## 2. Запуск сервера

```bash
./network_server
```

Сервер слушает:

```text
http://127.0.0.1:8080
```

## 3. Проверка вручную

В другом терминале:

```bash
curl "http://127.0.0.1:8080/health"
```

Ожидается:

```text
OK
```

Затем:

```bash
curl "http://127.0.0.1:8080/api/calc?a=10&b=20"
```

Ожидается:

```text
30
```

## 4. Клиент

```bash
python3 client/client.py
```

Ожидается:

```text
HTTP status: 200
10 + 20 = 30
```

## 5. Нагрузочное тестирование

Установить k6 по официальной инструкции, затем:

```bash
k6 run loadtest/network_test.js
```

Тест создаёт 20 виртуальных пользователей на 30 секунд.

Проверяется:

- HTTP status = 200;
- ответ = `30`;
- доля ошибок менее 1%;
- p95 времени ответа менее 500 мс.

Параметры можно изменить в `loadtest/network_test.js`.


## 7. Архитектура

```text
+----------------+       HTTP/TCP        +----------------------+
| Python client  | --------------------> | C++ socket server    |
+----------------+                        | :8080                |
                                          +----------------------+
                                                   ^
                                                   |
                                          HTTP load / k6
                                                   |
                                          +----------------------+
                                          | k6 load test         |
                                          +----------------------+
```
